# Authoring

This owner contains the canonical authoring session, artifact references,
provenance and retained guided journey. The original enum values and Valid
methods move with their types. Field order, JSON tags, nil/empty collections,
timestamps, native references and approval/operation identities stay unchanged.

Generated inputs and quiz records keep their existing child/domain owners.
Native admission uses workflow/state values; host callbacks, native store IO,
authority checks and execution remain outside this value layer. Session and guided validation
move with their values: required identity/role, managed revision, namespace,
actor/progression intent, finite retained-state bounds, valid stage/status and
canonical naming retain their original guard order and diagnostics. Native
admission still calls the original narrower intent predicate; it does not
substitute full-session validation. The original file-backed session repository, artifact IO, journal/recovery and
guided transitions now live here with their genuine ports. No root alias or forwarding API is
provided for the relocated values.

GuidedWorkflowObserver is the consumer-owned boundary for native stop,
original-admission and verified-result observations. Its native adapter uses the
existing bound reader, original request lookup and result proof inspection with
their locks, authority guards, error identities and partial outcomes. Stop
acceptance and quiescence stay distinct; absence stays separate from read error.
Result projection reuses GuidedResultReference and the original native update
time. Authoring retains its lock, transition and journal order; the port admits
no work and changes no native policy or dispatch.

Native admission, preview membership, materialization projection and result proof
checks remain with the existing workflow owner in separate native files. The
original guided scope guard is shared here. Native admission and control read a
session only through ReadOwnedSession while the same active authoring
claim is held; native proofs and inner store locking remain with their owner.
Plan delivery resume also remains native because it reads the locked workflow
snapshot and original materialization contracts/receipt. No second repository or
coordinator is introduced by the separation.

Shared document context, source kind/class values, partial document/source loads
and source inventory rendering belong here. Native runtime/execution context
assembly stays with the original RuntimePlan, indexed ticket/parser and complete
execution/result validation owners. That retained IO consumes these shared
values directly; it is not authoring session or document publication behavior.

QuizContextProvider supplies the original workspace/index observations explicitly.
The contextual quiz caller loads it at the original point after layout selection
and before model invocation. Request construction then uses the observed sections
without IO. The concrete workspace context and harness adapters retain graph
projection, host binding/runner, output validation and trace behavior outside the
authoring decisions. Existing real adapter fixtures retain their assertions.

The complete original authoring aggregate and dump/spec/plan artifact behavior
are owned here. Shared exclusion, scope/path guards, atomic journal replacement,
recovery, exact source observations, retry receipts and Git checkpoint ordering
remain one implementation. Native consumers call the actual artifact validators
and codecs; the old root package has no compatibility aliases or forwarding API.
Native integration tests remain beside the native owner; authoring journal fault
and metadata tests move with this aggregate, retaining their original assertions.
