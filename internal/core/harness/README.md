# Retained harness identity

This owner contains the existing executable reference, semantic binding, role
and role constants shared by retained admission inputs and their native caller.
Field order, JSON tags, capability fields and serialized spelling are unchanged.

The adapter-neutral capability value comes from internal/harness. Selection,
profile interpretation, binding validation, hashing, host preparation and process
execution stay with their current owners. This package has no workflow, provider
client, filesystem or configuration dependency.
