This use case covers the interactive console.

The TUI should provide a project-manager view over ChrysoCoord state: projects, cases, dumps, quizzes, specs, plans, tickets, board columns, runtime execution, reports, and dashboard state. It should mirror CLI workflows where practical and keep actions discoverable without requiring users to memorize commands.

The TUI is the primary experience for observing and steering ongoing agent work.
