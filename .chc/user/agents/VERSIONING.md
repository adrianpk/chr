# Versioning

## Commits

Use Conventional Commits:

```text
<type>(<scope>): <description>
```

Common types:

- `feat`
- `fix`
- `docs`
- `refactor`
- `test`
- `chore`

## Branches

Prefer short-lived branches from the project trunk for implementation slices.

Do not rewrite shared history without explicit approval.

## Pull Requests

Target the active development branch unless the project documents a different flow.

Include summary, validation, and known risks.
