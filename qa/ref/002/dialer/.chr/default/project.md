Dialer is an early-stage Go CRM service for lead calling workflows. It models
leads, agent queues, call outcomes, conversion decisions, and follow-up work.

The project is designed for chr screenshots. It includes enough seeded
context to show dumps, quizzes, generated specs, plans, trackers, tickets, board
columns, and agent work surfaces without requiring a live agent run.
