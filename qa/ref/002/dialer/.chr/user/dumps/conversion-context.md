# Conversion Context Dump

Conversion is the point where a lead becomes a prospect. It should only happen
after a qualifying call outcome. The user should be able to inspect which ticket
owns the transition rules, which tests prove the status changes, and whether a
blocked ticket is waiting on a domain decision.

The first version can keep prospects in memory. It does not need account
management, billing, sales stages, or external CRM sync.
