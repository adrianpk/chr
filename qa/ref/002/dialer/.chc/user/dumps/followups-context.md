# Follow-ups Context Dump

Follow-ups represent future work created by call outcomes. If a lead asks for a
callback next week, the dialer should record that time and keep the lead out of
the active queue until due.

The UI should make follow-up work visible without requiring real calendar
integration. A small in-memory model is enough for screenshots and ticket
workflow testing.
