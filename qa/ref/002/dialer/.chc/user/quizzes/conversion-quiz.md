# Conversion Quiz

## Summary

Conversion should be explicit and rule-based. A lead can become a prospect only
after a qualifying call outcome. Lost and do-not-call leads cannot be converted.

## Curated Answers

- Conversion creates a prospect record or prospect state.
- Qualified is the only initial conversion source.
- Lost and do-not-call states block conversion.
- The API should return JSON client errors for invalid transitions.
