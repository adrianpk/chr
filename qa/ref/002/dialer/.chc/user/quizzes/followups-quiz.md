# Follow-ups Quiz

## Summary

Follow-ups are callbacks scheduled from call outcomes. They should be visible as
future work and become callable when due.

## Curated Answers

- A callback outcome should create a scheduled follow-up.
- Not-yet-due follow-ups stay out of the active queue.
- Due follow-ups return to the queue.
- Calendar integration is out of scope.
