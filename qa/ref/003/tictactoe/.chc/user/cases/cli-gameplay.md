name: "CLI Gameplay"
description: "Run a complete local two-player tic-tac-toe game in the terminal."
---

Two players should be able to run `tictactoe` and play a full game from the
terminal. The CLI should display the board, prompt for moves, alternate turns,
reject invalid input without losing the turn, and announce either a winner or a
draw.
