# chr Workspace

This directory stores chr's project-local working material.

The Markdown files in this workspace are meant to be inspectable and editable
when you know what you are changing. Runtime logs, indexes, locks, and traces
are operational records derived from project activity.

## Useful Places

- `tickets/` stores project-local work items.
- `specs/`, `plans/`, `trackers/`, `dumps/`, and `quizzes/` store authoring
  and planning artifacts.
- `reports/` stores durable run, audit, and handoff records.
- `runtime/` stores sandbox execution assets and evidence.
- `indexes/` stores derived lookup state.
