# Invariants

## Scope

- Execute only approved scope.
- Do not add unrelated work.
- Record out-of-scope ideas instead of implementing them.

## Safety

- Do not overwrite user files unless explicitly requested.
- Do not run destructive git operations without explicit approval.
- Treat `.chc/` as project-local operational state.

## Validation

- Run relevant validation before handoff.
- Report commands and outcomes.
- Do not mark work complete with known failing checks unless the failure is the explicit subject of the task.
