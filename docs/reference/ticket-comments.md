# Ticket Comments

## Purpose

Ticket comments append coordination notes to Markdown ticket files.

Markdown ticket files remain the canonical ticket source. Comments are stored in
the existing `# Comments` section generated by the ticket template.

## CLI

Append a comment with:

```sh
chr ticket comment <key> <comment>
```

The command accepts the standard ticket project flags:

- `--dir` to resolve a project directly;
- `--dev-root` for development-mode user state.

It also accepts:

- `--author` to record the comment author.

## Behavior

The command:

- resolves the project through the command project context resolver;
- finds the ticket by key in the user-level ticket index;
- appends a timestamped comment under `# Comments`;
- updates the ticket `updated_at` frontmatter field;
- writes the modified Markdown ticket file.

## Scope

The command does not rebuild the ticket index.

The command does not change ticket status.

The command does not implement threaded comments or external messaging
integration.
