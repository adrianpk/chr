complete frozen attachment. Confirmations retain their complete scope and
existing guards. Progress distinguishes admission, validation, human waits and
native integration. Workflow notifications use the same presentation/document
values under their existing event owner.

captions, six nonempty lines/600 units for opening excerpts, 2 MiB per complete
attachment and 64 MiB retained payload per owning database. Delivery retry,
plain fallback and reopen retain original bytes, action identity and consumed
allowance. Completed domain results survive presentation or delivery failures.
