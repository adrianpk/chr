Pause and cancellation persist stop intent before releasing work ownership.
Only quiescent, fenced attempts can journal a retained checkpoint. Resume keeps
consumed retry budgets and restores the prior integration barrier. Cancellation
is terminal and does not validate or integrate a stopped task.

Each command journals its Linux boot/PID/birth identity before launch permission.
A surviving supervisor retains serial capacity for its process group and enforces
the finite worker lifetime after host loss. A shared durable process-group ledger
blocks native and legacy starts if the supervisor disappears before a child stops.
Bounded command output is synced to retained files. Recovery verifies process
quiescence and every owned lock before changing task state, then retains input,
lane, output hashes, replacement history and checkpoint evidence.
