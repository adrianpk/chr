# Ticket Workflow

Use tickets as the operational unit for mutating work.

## Ticket Lifecycle

Suggested statuses:

- `open`
- `ready`
- `in_progress`
- `reviewing`
- `blocked`
- `solved`
- `closed`

## Rules

- Keep one ticket focused on one unit of work.
- Record blockers explicitly.
- Attach validation evidence when work is completed.
- Preserve comments that explain user decisions or unblock execution.
