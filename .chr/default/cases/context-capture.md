This use case covers dumps, quizzes, metadata, ADR-aware discovery, and workspace context assembly.

chr should help the user move from rough project knowledge to durable context artifacts. Dumps preserve broad context. Quizzes put the agent in a requirements-analysis role and reveal missing domain details. Metadata identifies project-wide and use-case-specific scope.

The output should remain editable Markdown and should be usable by later spec, plan, ticket, and execution workflows.
