# Existing Project Material Map

Status: active

This repository already had project material before `.chr/default/` adoption.

## Existing Product Documentation

- `README.md` describes the public product entry point.
- `docs/index.md` links Diataxis-organized documentation.
- `docs/tutorials/` contains learning-oriented walkthroughs.
- `docs/how-to/` contains task-oriented guides.
- `docs/reference/` contains command and artifact contracts.
- `docs/explanation/` contains design rationale and system model documents.

## Existing Delivery Material

- `ops/specs/` contains formal implementation specs.
- `ops/plans/` contains implementation plans.
- `ops/trackers/` contains tracking documents for planned work.
- `.prj/reports/slices/` contains slice delivery reports.

## chr Workspace Material

Going forward, `.chr/default/` is the project-local workspace chr commands read and write.

Seeded `.chr/default/` material should summarize or point to existing material instead of pretending old work was produced by the new workspace.
