# Lifecycle

## Work Phases

1. Align on the task.
2. Plan when the task requires a plan.
3. Implement the approved scope.
4. Validate the changed behavior.
5. Report outcome and remaining risks.

## Blocked Work

When blocked:

- state the blocker precisely,
- include relevant command or error output,
- stop without speculative side changes,
- record the blocker on the related ticket or tracker when one exists.
